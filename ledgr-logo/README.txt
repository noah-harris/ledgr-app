ledgr logo files

favicon/   Drop these in your web root and paste head-snippet.html into <head>.
           favicon.svg switches to a light version when the browser is in dark mode.
svg/       Vector masters. Wordmark text is outlined, so no font is needed.
png/mark       Full checklist mark (3 rows), 16-1024 px. Best at 64 px and up.
png/icon-mark  Simplified mark (2 rows), 16-1024 px. Use for small sizes.
png/app-icon   Rounded-square app icons, light and dark.
png/logo       Horizontal / stacked lockups and wordmark, by height.
*-on-dark files are for dark backgrounds. All PNGs are transparent except app icons.
Colors: ink #161616, grey #9A9A9A, paper #FFFFFF, light #F5F5F5. Font: Reddit Sans ExtraBold.

Note: the 16 px favicon (svg/ledgr-favicon-16.svg) is a pixel-tuned version with one check, since the full mark blurs at that size.
